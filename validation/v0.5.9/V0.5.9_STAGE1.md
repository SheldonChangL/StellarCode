# StellarCode v0.5.9 first-turn context delivery: Stage 1 result

**Decision: FIRST-TURN DELIVERY PARTIAL.** The pre-registered primary target was not met, and Stage 2 and `stellar preflight` were not run.

- Prefetch cut repo-median input by 26.6% and model turns by 26.6% with identical correctness.
- The pre-registered duplicate-verification gate failed: 25.0% for pull, 27.8% for prefetch, 30.6% for prefetch-contract.
- Early stop was not triggered.

## Verification behavior

- **No duplicate-read cost.** Re-reading delivered source is rare in bytes: 0.3–1.9% of delivered bytes in every condition.
- **The gate measured a mechanism that turned out not to be the cost.** The duplicate-verification *rate* is about one run in four in pull too, where the agent re-reads source that `stellar context` already returned.
  - Moving delivery to the first message did not lower that rate.
  - The grounding contract did not lower it either. On patentskill it rose (25 → 50%).
- **The contract adds nothing measurable.** It used more input than plain prefetch (20.3% versus 26.6% repo median) and did not reduce verification. It is not recommended.

## Causal conclusion: is the extra round trip the main reason?

**Yes, for the savings measured here.**

- **Turns.** Mean model turns fell by 1.14 per run (4.36 → 3.22). That is the one `stellar context` round trip pull spends before it sees any source.
- **Behavior after the context arrives is unchanged.** Turns with tool use after grounded context were 2.36 for pull and 2.22 for prefetch.
- **Tokens.** The envelope adds about 2.8K tokens to the first turn (34.7K → 37.5K). Removing a whole turn of cached-context re-reading saves about 40K median in later turns (119.5K → 79.4K).
- **What delivery does not change.** It does not change how many verification and exploration turns the agent spends afterwards, about 2.2 per run. Those turns are concentrated where the top target is wrong (9 of 12 tasks). They are the remaining lever, and ranking quality drives them, not delivery.

## Ranking problems recorded (not changed)

Following the experiment rules, ranking was not touched. The frozen v0.5.7 ranking puts a correct first target on only 3 of 12 Stage 1 tasks.

If that confirms per-repository input and turn reductions ≥ 15% with equal correctness, add the generic `stellar preflight` command.
