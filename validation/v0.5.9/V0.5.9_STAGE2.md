# StellarCode v0.5.9 first-turn context delivery: Stage 2 confirmatory result

**Decision under the pre-registered rule ([STAGE2_AMENDMENT.md](STAGE2_AMENDMENT.md)): FIRST-TURN DELIVERY REGRESSION.**

- The rule decides REGRESSION because goodjobshare prefetch grounded success (95.83%) is below pull (100%).
- That gap comes from one run. In that run the agent *did* read the expected files, but through shell commands the harness cannot attribute (a glob and a `cd`-relative `cat`); see "Grounding failures" below.
- **Sensitivity.** Treating that read as grounded gives **PARTIAL**, not CONFIRMED. goodjobshare (input 14.65%, turns 14.75%) and patentskill (input 13.62%) miss the 15% gates either way.
- **First-turn delivery did not generalize at the pre-registered strength.** `stellar preflight` is not implemented.

## Setup

- **Runtime.** `e237d61`, the amendment commit, recorded by every campaign. `dirty: false`, and `changedDuringCampaign: false` for all three. `src/`, `bin/` and `package.json` are unchanged since Stage 1.
- **Tasks.** The 24 confirmatory tasks: the frozen v0.5.8 sets minus the Stage 1 subset, 8 per repository, with no re-selection. Task-set hashes were verified at campaign start.
- **Runs.** `pull` and `prefetch`, repeat 3, **144 runs, all completed**.
  - The order was rep 1 pull → prefetch, rep 2 prefetch → pull, rep 3 pull → prefetch. Each row records it as `conditionOrder`.

It is recorded here and **not fixed**. The runtime and harness stay frozen, and re-scoring after the results would change the evaluation post hoc.

## Causal reading

- **The mechanism held.** Prefetch removes about one model turn: mean turns fell from 4.92 to 4.03. It does not change the turns spent after the context arrives: 2.92 versus 3.03.
- **The size of the effect depends on the task.**
  - The envelope adds about 2.3K tokens to the first turn. Each removed turn saves one cached-context re-read, about 35–40K tokens.
  - The relative saving therefore scales roughly as 1 / (pull model turns). The Stage 2 tasks were longer (pull mean 4.92 turns, versus 4.36 in Stage 1), so the same one-turn saving was a smaller fraction.
  - Six tasks saved no turn at all: in those the agent explored as many rounds as it would have anyway.
- **Stage 1 overestimated the effect.** The pilot measured 26.6% at the repo median; the confirmatory set measured 14.65%.

## Did first-turn context delivery generalize across the three repositories?

**No, not at the pre-registered strength.**

- It generalized as a direction: each repository saved input and turns, at 13.6–25.5%, without losing answer correctness.
- Only kc002-ota cleared both 15% gates.
- The official decision is REGRESSION, caused by a harness attribution defect. Without that defect the outcome is PARTIAL.
