## Semantic failures (diagnosed after the run, not fixed)

**1. Target selection dominates (end-to-end recall 4.1% versus index recall 51.4%).**
- The slice expands from the lexical top target, which is wrong in 27 of 36 tasks.
- On audit-orders, all 11 symbol primaries are in `src/models/interfaces/*`. These are type-only namespace members (`IPoint.ts#Stop`, `Common.ts#ServiceResponse`), and the twelfth task's primary is the module `src/index.ts`. A type has no callers, so the slice returns 0 edges for most tasks.
- **Correction to an earlier hypothesis.** v0.6 did not cause this. Re-parsing with the `main` (v0.5.6) parser gives 206 symbols for `src/models/interfaces/*` against v0.6's 209, and 215 against 216 for the rest of `src/`. The bias is the v0.5.6 lexical ranker on a repository whose interface files carry much of the domain vocabulary.

**2. Symbol-range defects inherited from the v0.5.6 parser (most index misses).**
- A JS/TS function whose parameter list contains a destructuring `{` gets a one-line range, for example JetBook `PATCH(req, { params })` and React components with destructured props.
- A Python `def` with a multi-line signature ends its block early.
- Calls inside such bodies are attributed to module level, so a function-level edge never forms. In the returned slices this appears as `(module level)` callers, for example `src/actions/settings.ts:86` and `backend/app/redmine_token.py:91`.

**3. Intent misclassification.**
- 13 of 36 tasks were classified differently from the authored category, mostly impact or editing-prep classified as navigation.
- These tasks get the 3-edge, incoming-only navigation slice, which cannot contain the outgoing chains that were annotated.

**4. Python is resolved conservatively** (`semantic-partial`). Redmine-AI-agent has the lowest index recall (9/32): receivers without type evidence, `self.x` fields with unknown provenance, and module-attribute calls through imported modules do not resolve.

**5. Irrelevant but true edges.** The slices that were returned are often about the wrong behavior. For example, a JetBook flow task about autosave conflicts received `restorePageVersion` edges, and a Redmine task about issue filters received `_validate_against_redmine`. They cost context bytes: JetBook's median `contextSourceBytes` is 4306 (lexical) against 5194.5 (semantic), and source bytes read rose by 7–8% in two repositories.

## Edge audit (semantic catastrophe check)

**Scope.** All 69 distinct semantic edges that the `stellar` condition returned to agents across the 36 holdout tasks (the runs' `semanticEvidence`). All 69 are `high` confidence. The edges are deterministic, so every repetition received the same set.

**Method.** An independent fresh-context reviewer checked each edge against source in the holdout worktrees, including imports, re-exports, shadowing and same-named definitions. The per-edge verdicts are in `holdout/edge-audit.json`.

| Repo | True | True, caller attribution wrong | False |
|---|---|---|---|
| audit-orders | 3 | 0 | 0 |
| JetBook | 37 | 6 | 0 |
| Redmine-AI-agent | 14 | 9 | 0 |
| **Total** | **54** | **15** | **0** |

- **No high-confidence false relation.** Every edge's call or use reaches the exact target definition. There is therefore no semantic catastrophe and no repeated false relation.
- **15 edges name the wrong caller.** Each claims a `(module level)` caller, but the line is inside a named function. Examples:
  - `src/actions/settings.ts:86` is inside `changePasswordAction`, whose `(input: {` parameter list spans lines.
  - `backend/app/redmine_token.py:91` is inside `put_redmine_token`, whose `def` signature spans lines.
  - Next.js `export default async function` pages are affected the same way.

  This is failure 2, the inherited symbol-range defect. The target is right but the "from" end is imprecise, so `semanticPathLength` cannot chain through these callers. It is not counted as a false edge, but it is listed here as a correctness defect of the relation metadata.

- There were no correctness losses and no case with more than 2× the tool calls.

- One, `nav-editor-autosave-delay`, is attributable to the semantic slice: the wrong target produced six true but irrelevant edges, and the agent read more.
