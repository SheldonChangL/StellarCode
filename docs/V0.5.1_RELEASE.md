# StellarCode v0.5.1 — Evidence Before Claims

v0.5.1 adds a controlled token-efficiency benchmark for Claude Code and Codex CLI.

## New commands

```text
stellar benchmark init
stellar benchmark doctor
stellar benchmark run
stellar benchmark report
```

## What changed

- real agent-reported token telemetry rather than text-length estimates;
- fresh process/session per benchmark condition;
- detached Git worktree at identical HEAD per run;
- baseline `stellar` disable shim;
- Stellar condition pinned to the packaged CLI;
- isolated StellarCode data/cache directories;
- benchmark worktrees strip only the StellarCode navigation rule inserted by StellarCode itself;
- user-configured MCP/config isolation where supported by the agent CLI;
- hidden answer-key correctness checking;
- source-read/tool/search/time telemetry;
- paired JSONL logs + manifest;
- JSON and standalone HTML reports;
- evidence gate that refuses to claim success without correctness verification.

## Default evidence gate

- overall input-token reduction >= 20%;
- navigation input-token reduction >= 50%;
- tool-call reduction >= 40%;
- median time-to-first-relevant-file reduction >= 40%;
- correctness regression no worse than 5 percentage points.

## Scope

v0.5.1 benchmarks read-only repository navigation. It does not yet score code-edit quality or test/build success after an agent modification.

No real token-saving percentage is bundled as a claim. Users must run the harness on representative repositories/tasks with their authenticated agent CLI.
