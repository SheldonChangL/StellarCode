# StellarCode v0.5.2 Release

## Purpose

Make Stellar-assisted agent answers source-grounded after the first real A/B benchmark showed large token savings but a 100-point correctness regression.

## Changes

- Added `stellar source <path> --lines START:END`.
- Added MCP tool `stellar_source`.
- `stellar context` now emits symbol evidence, bounded read ranges, and a source-grounding policy.
- Agent rule now forbids implementation answers from Stellar summaries alone.
- Benchmark prompt requires an actual source read before implementation claims.
- Benchmark telemetry distinguishes discovery, source grounding, answer correctness, and grounded success.
- A correct-looking answer without a source read now fails.
- `filesOpened`/`sourceBytesRead` now measure actual read-like tool operations rather than any command that merely mentions a file path.
- Benchmark-only Stellar trace records query/source evidence without affecting normal runtime.
- Fixed JS/TS class-method start/end lines used by source read plans.
- Report schema upgraded to v3.

## Upgrade

Run `npm link`, then run `stellar scan` once in repositories used for source-grounded benchmarking so corrected symbol ranges are rebuilt.
