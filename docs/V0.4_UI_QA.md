# v0.4 UI QA Notes

## Stress case

A generated 481-file TypeScript repository was indexed with:

- 7 top-level galaxies
- 19 logical modules
- 959 symbols
- 989 graph edges

The purpose of this fixture was to reproduce the density class seen in a real 480-file repository without including any user source code.

## Acceptance checks

- [x] Default overview does not render all 481 files.
- [x] Default overview does not render all 989 edges.
- [x] Galaxy view remains legible at 1600×1000.
- [x] Module view contains only modules inside the selected galaxy.
- [x] File view contains only files inside the selected module.
- [x] Selected file dims unrelated nodes.
- [x] Direct cross-module dependencies appear as external satellites.
- [x] Impact mode adds reverse-dependency nodes on demand.
- [x] Inspector identifies architecture role and reason.
- [x] Search can navigate directly into the appropriate galaxy/module/file layer.
- [x] Breadcrumbs return to higher hierarchy layers.
- [x] Reduced-motion CSS remains present.

## Design rule

> The repository graph is the data model; it is not the default visual state.

The canvas should show the minimum graph needed for the user's current navigation depth.
